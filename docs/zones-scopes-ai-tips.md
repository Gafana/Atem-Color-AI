# Зоны, приборы и «ИИ-подсказки»

## Зона замера во всех режимах
- Прямоугольник рисуется мышкой на превью в **любом** режиме (в режиме «Шахматка» — четырёхугольник мишени). Правый клик / «Сбросить область» — убрать зону.
- Зона хранится по камере («Разметка для: CAMx»). Без ATEM/камер зона хранится для текущего входа (на время сессии).
- **Все приборы** (waveform, парады, вектороскоп, гистограммы, CIE, сравнение) считаются только по зоне; без зоны — по всему кадру. В углу прибора — метка «Зона» / «Весь кадр».
  False Color и Зебра рисуются на всём кадре, но всё вне зоны затемнено.
  Кадр сравнения (эталонная камера) берётся по зоне эталонной камеры.
- **Сведение не меняется**: в режимах по зоне (эталонная камера, серая карта, общий образец, шахматка) зона по-прежнему задаёт замер; в режимах по всему кадру (нейтральный баланс, эталонный кадр, авто в камере) сведение считает весь кадр, а зона влияет только на приборы и «ИИ-подсказки».

## Смена прибора из заголовка панели
Клик по названию прибора в заголовке панели открывает список всех приборов (включая «ИИ-подсказки»); выбранный прибор встаёт на место текущего в той же панели, раскладка сразу сохраняется (сессия `__last_session`). «ИИ-подсказки» — одна панель: при выборе в другой панели старая закрывается.

## «ИИ-подсказки»
Кнопка «Анализ»:
- **ATEM подключён, вход = AUX, камеры отмечены «В подстройке»**: AUX по очереди переключается на отмеченные камеры, кадр захватывается, AUX возвращается на исходный источник. Для каждой камеры — замечания, для неэталонных — сравнение с эталоном (ΔE2000 среднего цвета, разница уровня, разница баланса белого) с конкретными действиями.
- **Без ATEM** (или вход не AUX): анализируется текущий кадр с входа.
- Учитывается зона камеры (или зона входа); без зоны — весь кадр.

Правила (`src/color/FrameAdvisor.cpp`, тесты `tests/tst_frameadvisor.cpp`):
| Код | Что | Порог |
|---|---|---|
| black | чёрный кадр (98 % < 3 IRE) — остальные правила не применяются | — |
| clip | пересвет по каналам (≥ 99 IRE), отдельный совет если клипует один канал | ≥ 0,5 % (≥ 5 % — проблема) |
| crush | завал чёрного (все каналы ≤ ~1 IRE) | ≥ 3 % (≥ 20 %) |
| exposure | медиана против целевого IRE (весь кадр), в ступенях диафрагмы; для зоны — инфо об уровне | ±12 IRE |
| cast | оттенок нейтральных участков (C* < 15) в Lab a*/b* → направление K / Tint | ≥ 4 (≥ 10) |
| oversat | C* > 75 или пара «канал в клипе + пустой канал» | ≥ 1,5 % (≥ 8 %) |
| skin | угол телесных тонов против линии 123° на вектороскопе | ≥ 8° (≥ 15°) |
| noise / gain | СКО яркости в ровных блоках 8×8; Gain ≥ 18 dB | ≥ 1,5 IRE (≥ 3) |

Проблемные области (сетка 24×14 → связные области) отмечаются на превью пунктиром для выбранной в панели камеры (галочка «Отметки на превью»).

# Проверка с камерами Micro Studio 4K G2 (после ночной работы 2026-11-16)

## Подготовка
1. Камеры подключены к HDMI 1–4 ATEM Mini Pro; формат камер = формат пульта (1080p25).
2. В камерах (или в ATEM Software Control → Камера) выключить авто-ББ и авто-экспозицию —
   иначе камера «спорит» с поправкой.
3. AUX (выход HDMI) → DeckLink Mini Recorder 4K. В приложении «Источник»: IP 192.168.2.127,
   «Подключить», устройство DeckLink, режим 1920×1080@25. Кнопка «AUX = Программа» возвращает эфир на выход.
4. Таблица «Связка камер»: CAM1–4 → входы 1–4 (метки «без Camera Control» у них быть не должно; у DIR — есть, это нормально).
   Двойной клик по строке — AUX показывает эту камеру (быстрая проверка соответствия).
5. Закрыть OmniScope/Media Express, если они держат DeckLink (иначе превью пишет ошибку и повторяет запуск каждые ≤10 с).

## Проходы
1. Режим «Авто: баланс + экспозиция» → «1. Захват и расчёт». Пульт сам переключит AUX по камерам и вернёт.
2. Таблица: ошибка IRE / ΔE2000 до→после, «Что изменится», «Внимание» (красным — крупные шаги).
3. «2. Применить…» → отметить камеры → подтвердить. Уровень за проход ограничен ±1 ступенью —
   повторить захват 2–3 раза до сходимости (ошибка < 1–2 IRE).
4. «Откат» возвращает значения, прочитанные с камер перед применением.
5. Режим «По эталонной камере»: эталон — лучшая камера; остальные подгоняются по гистограммам.
6. «По общему образцу»: выбрать «Разметка для: CAMn», выделить один и тот же объект (белый лист / лицо)
   на каждой камере (рамки сохраняются), цель — эталон / среднее / нейтраль.
7. «По таблице цветов»: таблица в кадре каждой камеры, 4 угла, пресет таблицы (CC24 и др.).
8. «Авто в камере»: команда авто-ББ (и по галочке авто-диафрагма) — потом снова выключить авто в камерах.

## Пресеты
«Пресеты камер → Сохранить…» «День» / «Вечер» (читаются текущие значения камер), «Применить» —
отправляются только отличающиеся группы.

## Что смотреть в журнале (acai-app.log / консоль)
`AUX 8001 restored to 10010`, `match CAMn … Gain …`, `sent mode=… dest=n …`, `ATEM connection lost`, `preview stalled`.

# Blackmagic ATEM Switchers SDK — заметки о лицензии

Текст лицензии выдаётся при скачивании SDK/ПО с сайта Blackmagic (EULA в окне загрузки). Полный текст в репозитории **не хранится**.

По публичным формулировкам **Standard Blackmagic SDK** (и аналогичным условиям загрузки ATEM Switchers SDK):

- Лицензия **неисключительная, непередаваемая**, royalty-free.
- **Запрещено** сдавать в аренду, **распространять** или **сублицензировать** файлы SDK и сопутствующее ПО Blackmagic.
- Официальный канал получения SDK — только сайт Blackmagic, принятие EULA при загрузке.

Следствия для **Atem-Color-AI**:

1. Файлы SDK **не коммитятся** и **не входят** в NSIS-инсталлятор.
2. На Windows используется **COM-сервер BMDSwitcherAPI**, который регистрируется при установке **ATEM Software Control / Blackmagic ATEM Switchers** у конечного пользователя.
3. Сборка в CI с секретом `ATEM_SDK_URL` загружает SDK **только на время сборки** (в частности IDL для `midl`); артефакт релиза содержит лишь собственный бинарь приложения.
